# Atrinik agent integrations

This repository owns reusable Atrinik development skills and their supporting
resources. Keep repository-specific authority and operational implementations
in their owning Atrinik repositories. Codex MCP configuration is separate.

All distributed material must be MIT-compatible with preserved attribution.
Use synthetic fixtures. Never commit credentials, private records, host state,
personal paths or unrelated project material.

Use owned worktrees for concurrent writers and preserve others’ changes.
Validate skill behavior, references and invocation policies before publication,
and retain independent review. Remote writes require fresh repository identity,
permissions, branch and revision checks. No implicit merge or deployment.

Organization community files provide shared issue forms, security policy,
code of conduct and pull-request templates; avoid redundant copies.
